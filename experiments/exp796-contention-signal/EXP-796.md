# EXP-796 — Determinism-floor measurement + contention signal (accidental)

**Status: VOID** per pre-declared gates (receipt #112) — but two decisive
findings and one promoted hypothesis.

## What was tested
FP-robust re-test of the exp795 inline steal: 8 arms on patched binary
`eba566fb` — P1/P2 (passive, no flag), DP1-3 (passive +
MOE_GROUPED_DETERMINISTIC=1), DA1-3 (steal ON + flag). Probe = probe795.py
verbatim (`c995fa174be30136`). Design sha `864743f83c6cbe1c` (prereg).

## Findings
1. **Intrinsic nondeterminism**: H(P1,P2) = **85/256** with same binary,
   same config, fresh processes. Greedy decode on this stack is not
   run-to-run reproducible (atomicAdd accumulation + FP chaos).
2. **MOE_GROUPED_DETERMINISTIC=1 does not deliver token reproducibility**:
   H(DPi,DPj) = 150/173/123 — worse than unflagged. Gate 0 "flag
   insufficient" branch taken; Gate 1 divergence (162/101/161) => VOID.
   Bit-level correctness gates are permanently unusable for this stack;
   statistical floors are the only valid instrument.

## Observational perf (confounded — not promoted)
- DA mean 9.469 vs DP mean 5.947 (+59.2%, separated) — BUT the battery ran
  under host load (15-min loadavg 8.64 during run; GPU0 CI job; buildkitd)
  AND arm order was sequential (passive early/heavy load, steal late/
  recovery; DP3=7.81 marks the transition). Direction matches exp795's
  quiet-host +6.8%; magnitude unreliable.

## Promoted hypothesis (exp797)
Inline steal is host-CPU-contention resilient: caller-thread execution
avoids worker-thread wakeup starvation on busy hosts. Test: interleaved 2x2
(steal x deliberate taskset-pinned CPU burn), ABBA order, 3 reps/cell,
correctness via divergence-floor comparison vs the measured 85/256 intrinsic
floor.
