**Findings.**
1. **S1 closure: P1 PASS decisively.** Cross-process greedy nondeterminism is severe (BASE-vs-BASE agrees on only 48.1% of token positions — exp796/804 confirmed at scale), but BASE-vs-PATCH best-pair agreement is 66.8%, **higher** than baseline self-agreement. The patch adds no divergence; if anything its runs land closer to baseline. exp812's sampled-prefix evidence is now backed by a full-1024-position agreement comparison. **The one-file patch is behavior-preserving by the strongest available criterion; upstream-PR gate closed.**
2. **Residual ops are HF model math, not engine glue** (G1 FAIL at site granularity, but grouping is tight): RMSNorm forward (`modeling_olmoe.py:54-57`, add/mul/_to_copy) ≈ 39% of samples; `linear.py:134` reshape pair (view + _unsafe_view) ≈ 16%; rope muls (`:154-155`) ≈ 8%; dispatch wrapper `module.py:1833 inner` ≈ 8%. ~63% in two files.
3. **The remaining ~1,800 ops/tok need kernel fusion, not bookkeeping cleanup**: fused RMSNorm (one kernel for add/mul/cast), fused rope, and fused linear-reshape would each strike hundreds of ops/tok. This is the fork-in-the-road: kernel work (harder, bigger wins) vs accepting the current −17 ms/tok and packaging the fix upstream.
4. Cross-run greedy token identity is definitively dead as a gate class (48% baseline self-agreement); all future S1 gates must be agreement-vs-baseline or logits-level.
