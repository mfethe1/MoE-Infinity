# EXP-824 — A/A validation of the ABAB + bootstrap estimator

**Status: PRE-REGISTRATION (frozen before run; no gate, tolerance or rule below changes
after freeze).** Estimator-methodology experiment; no performance claim about the engine.

## Question

The min-of-3 wall estimator (per-arm min of interleaved reps, 2nd-min ≤ 1.10–1.12×min
co-check) is scheduled for replacement by paired ABAB blocks + bootstrap CI (three-model
panel 2026-11-14; Mythos 5.2 review 2026-11-18). Before any future A/B experiment relies
on the new estimator, its behavior on NULL data must be measured: on identical arms (A/A),
does the 95% bootstrap CI on the paired mean difference wrongly exclude zero, and how
wide is it on this rig?

## Design

- **Arms: A1 = A2 (identical).** Config: OLMoE-1B-7B-0125-Instruct, offload
  `/home/mfeth/moe-offload-olmoe-0125-r05`, policy `lcnu`, `device_memory_ratio 0.35`,
  `num_threads 4`, `gpu_only_expert_routing true`, `adaptive_resident_mode legacy`,
  `speculative_prefetch` off, probe8 prompts, greedy, `min_new_tokens =
  max_new_tokens = 128` (B3-style fixed length; token lists recorded per prompt).
- **Battery** = one fresh process: 1 throwaway WARM block, then 6 ABAB pairs
  (A1 A2 A1 A2 … alternating; 12 measured blocks). **Block** = all 8 probe8 prompts
  sequentially. **n = 6 batteries** (fresh process each), launched only in quiet
  windows (host load < 2.0, block-until-quiet budget 3600 s, GPU 0 untouched).
- **Truth standard (exp817):** un-instrumented measured blocks — no LD_PRELOAD, no
  sampler thread, no nvidia-smi polling inside a battery. Per prompt: decode wall
  (perf_counter around the decode loop), generated token IDs, phase marks. Host-state
  row captured between batteries only.

## Estimator (frozen exactly)

1. `stat(block)` = (Σ decode-wall ms over its 8 prompts) / (Σ actual generated-token
   counts, from the recorded token lists — never an assumed count).
2. `d_i = stat(A1 block i) − stat(A2 block i)`, i = 1..6, within battery.
3. Point estimate `mean(d)`; 95% CI = percentile bootstrap, 10,000 resamples of the
   6 diffs, seed 20261118 (fixed, stated, `numpy.random.default_rng`).
4. **False positive (battery level):** 95% CI excludes 0.
5. Reference, reported only (no gate): `min-stat(A1 blocks) − min-stat(A2 blocks)`
   — the min-of-3-style difference on the same data.

No `zip()` over token lists without an equal-length assertion (known truncation bug
class): a length mismatch between compared generations → battery INVALID, never a
silently truncated agreement score.

## Gates

- **G0 (token integrity):** every measured block has all 8 prompts with generated
  token-list lengths in {127, 128} (engine fixed-length contract, EOS inclusive; the
  exp821 family divisor behavior), and compared lists with unequal lengths → battery
  INVALID (never truncated). Exact per-block Σtokens is recorded and used as the
  denominator (no assumed 1024).
- **G1 (determinism floor):** per battery, mean greedy agreement rate of each block's
  generations vs that battery's first measured block ≥ 0.6503 (= exp821's same-config
  battery floor 0.6553 − 0.5pp), else battery INVALID.
- **G2 (primary, false-positive gate):** 0 of 6 batteries with CI excluding 0.
  PASS requires 0/6. Report the exact binomial upper bound (Clopper–Pearson, script
  computed) on the false-positive rate from the observed count, whatever it is.
- **G3 (reported, no pass/fail):** per battery, bootstrap CI half-width in ms/tok and
  as a percentage of the pooled A/A mean; the reference min-diff magnitude.

## Validity, missing data, budget

- INVALID battery: any G0/G1 failure, missing phase mark, non-zero process exit, or
  load > 2.0 detected at battery boundaries. INVALID batteries stay in the count of
  attempted batteries, are not replaced, and are excluded from G2's denominator only
  if the defect prevents CI computation; otherwise they count with their CI outcome.
- Any INVALID battery → attempt INCOMPLETE (reported, no credit sought, no top-up).
- One attempt. Wall budget 5 h; if quiet windows exhaust it, stop and report aborted.
- Claims discipline: only within-battery paired comparisons; all ratios/percentages in
  the writeup script-computed from the frozen seal and pasted verbatim, with the
  direction's denominator stated.
