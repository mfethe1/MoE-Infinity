# EXP-817 — Un-instrumented wall verification: the instrumented wins were mostly counter overhead

**Question.** Do the measured wins — hooks −13.5 ms/tok (exp812), fused RMSNorm −10…−13.8 (exp814/815), combined −27 — survive without the TorchDispatchMode op-counter harness?

**Method.** 9 arms, NO instrumentation (wall + token lists only), two conditions + pristine baseline. Attempt-1 (fixed order) failed S2 (41% within-condition spread from external CI bursts on the shared host) — wall VOID. Attempt-2: interleaved 3 reps of (HOOK, BOTH, PRIST) with per-rep source flips, **block-until-quiet gates** (GPU0/GPU1/loadavg, 900s budget), **min-estimator** per condition. One extractor filename bug (tags vs `_128` suffix) fixed by repair-extractor extract817c (formulas unchanged, extract805b/807b/808b precedent). Seal `0d918b9e…`.

**Adjudication — the instrumented wall deltas were largely harness overhead.**
1. The op-counter (`str(func)` + Counter per dispatch, ~11–19 µs/op) inflated every instrumented wall delta proportionally to dispatch count removed. Un-instrumented, removing 1,187 detaches/token is worth **≤1.5%** (0.9 ms/tok, at the edge of resolution) — detaches are cheap metadata ops, not wall work.
2. Fused RMSNorm's un-instrumented win is **4.4 ms/tok** — real (memory movement of fp32 upcasts) but 3× smaller than the instrumented 13.5. Combined chain: **5.3 ms/tok (~6.7%)**, not −27.
3. **S1 confirms the hook fix is output-preserving** (agreement 0.593 ≥ floor 0.554 − 0.5pp). Its value is code hygiene + dispatch reduction, not wall time.
4. **Belief update (corrects exp812/814/815 wall claims):** dispatch-count reductions do not translate 1:1 to wall; the only real per-token wall owners measured so far are memory movement (RMSNorm fusion −4.4), expert fetch (exp794: 43.7 pts of cost) and true compute. Counter-harness wall numbers must never be quoted as speedups again; un-instrumented min-estimator A/B with quiet gates is the standard.
5. PR #360 (perf PR) corrected accordingly: hooks = dispatch-hygiene + output-preserving (keep), fusion = opt-in eval-graded −4.4 ms/tok (~5.6%), not −13.5.

**Lineage.** exp812 (hook fix) / exp814-815 (fusion) → **exp817 (un-instrumented truth: −5.3 ms/tok combined; harness inflation exposed)** → exp818 (speculative prefetch vs fetch-wait, the real bottleneck).
