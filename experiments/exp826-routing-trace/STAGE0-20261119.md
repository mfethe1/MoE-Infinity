# exp826 stage 0 — router-trace overlap study (offline, counts-only)

Artifact: exp826-routing-steps.json (16 diverse prompts, 16 layers, greedy 64-token decode,
OLMoE-1B-7B top-8 of 64 experts/layer/step; run 2026-11-19T02:48Z, unit exp826-s0r2).
Analysis: analyze_routing.py (same directory) — every number below is its stdout.

## Findings

1. **Step-aligned expert overlap is ~12.5%** (mean pairwise Jaccard 0.1246 over decode steps
   1+; step 0 = shared chat-template prefill, overlap 0.995). Two prompts running concurrently
   share ~1 of their 8 per-step experts.
2. **A random b8 batch activates ~38 distinct experts per layer per step** (vs 8 for b1) —
   the per-step expert working set grows ~4.7x when batching 8 diverse prompts. This is the
   measured mechanism behind exp825's anti-amortization: more prompts = more dispatch events
   and more cache misses per step, not amortized fixed cost.
3. **Grouping headroom is small**: greedy best-8 pairing on first-8-step windows reaches 0.6206
   mean overlap vs 0.5383 random-pair (best single pair 0.7527). Even perfect pairing cuts
   distinct-experts-per-step by far less than the 25% threshold Mythos review #1 set as the
   kill line for the residency-aware-grouping lane.
4. ~~No hot-expert set to cache~~ **RETRACTED 2026-11-19 (adjudication)**: the union artifact
   (see 5) hid the per-layer structure. Recomputed per layer (adjudication): prompts touch 54.9
   of 64 experts per layer on average (uniform null 63.99); top-8 experts take 19-32% of slots
   (uniform 12.5%), top-16 take 36-51% — mild concentration exists. Temporal locality is strong:
   adjacent steps share 2.92 of 8 experts (null 1.00). Residency policy questions reopen only
   behind M2 counters, not from this trace.
5. ~~Whole-generation unions saturate~~ **RETRACTED 2026-11-19 (harness artifact)**: s0_routing.py
   tagged every layer with the same id (len(gates)), so the union JSON collapsed all 16 layers
   under one key; the true per-layer union Jaccard is mean 0.833 (min 0.574), not 1.0. The
   finding that union-level statistics carry no grouping signal still holds on the corrected
   numbers.

## Verdict (stage 0; corrected by adjudication session 2 — see M0)

**Expert-residency-aware grouping for diverse-prompt serving is DEAD at this granularity** —
kill basis upgraded by the adjudication: held-out 6+6 split grouping cuts distinct experts by
0.5% vs random, in-sample oracle over all 462 splits reaches only 2.7% (kill line 10%). The only surviving overlap
structure survives is ~~the shared-prefix effect~~ **RETRACTED 2026-11-19**: the 0.995 step-0
overlap is a harness artifact (wrapper kept idx[0] = the chat-template BOS position only, which
is token-identical across prompts); prompt-token routing was never recorded. exp825's batching result is now mechanistically explained:
batch multiplies per-step dispatch events ~4.7x at b8 while GPU math stays flat.
